# Alemni Mobile App (تطبيق علمني للهاتف)

تطبيق الموبايل مبني بـ **Flutter + Dart**.

## الخصائص الرئيسية (المراحل 4 - 6):
- واجهة عربية بالكامل RTL مع دعم عزل الجمل الإنجليزية LTR.
- المهارات الأربع: الكتابة (Writing) ← القراءة (Reading) ← الاستماع (Listening) ← التكلم (Speaking).
- قسم مخارج الحروف وحروف العلة (Phonics).
- ميزة مفرداتي + حفظ التقدم في وضع عدم الاتصال (Offline-first).
- إدارة الحالة عبر Riverpod، والتنقل بـ go_router، والصوت عبر `flutter_tts` و `speech_to_text`.
