# Alemni Admin Dashboard (لوحة تحكم علمني)

لوحة تحكم المشرف (Admin Dashboard) مبنية بـ **React + TypeScript + Vite**.

## المتطلبات والميزات (المرحلة 8):
- واجهة عربية بالكامل (RTL).
- تسجيل دخول Admin بنفس الـ JWT.
- إدارة المحتوى: الكلمات، القصص (مع الأسئلة)، جمل الاستماع والتكلم، عناصر النطق.
- استيراد CSV/JSON مع Validation ومعاينة واضحة.
- إحصائيات الاستخدام والتحليلات.
